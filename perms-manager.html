👥 مدير المستخدمين والصلاحيات

أداة تعمل على جهازك فقط (لا ترفع شيئاً). حمّل users.json، عدّل الصلاحيات وكلمات المرور ورمز GitHub لكل مستخدم، ثم نزّل الملف الجديد وارفعه إلى GitHub مكان القديم.

تذكير أمني: الصلاحيات (مسح/رفع/حذف) تتحكم في واجهة البرنامج. الحماية الفعلية لـ GitHub هي الرمز: من لا رمز له لا يستطيع الكتابة إطلاقاً. أعطِ كل من يكتب رمزاً Fine-grained محصوراً في مستودع الأرشيف فقط بصلاحية Contents: Read and write، وأنشئ رمزاً منفصلاً لكل مستخدم ليسهل إلغاؤه. الرمز يُشفَّر بكلمة مرور المستخدم، فاستخدم كلمات مرور قوية، ولا يعمل فكه إلا عند فتح البرنامج عبر HTTPS. بعد تغيير كلمة المرور أعد إدخال الرمز لإعادة تشفيره. ملف users.json المنشور على GitHub يظهر للمستخدمين خلال بضع دقائق (تخزين GitHub المؤقت).
