# 📁 هيكل البرنامج — أين كل شيء وماذا يفعل

> الدليل التفصيلي (الميزات والإعدادات وسجل التحديثات) في `docs/README.md`.

```
الجذر
├── index.html        الصفحة الرئيسية (نقطة الدخول). يجب أن تبقى في الجذر.
├── users.json        المستخدمون وصلاحياتهم (يقرؤه البرنامج من GitHub بمسار ثابت). يُعدَّل من شاشة «إعدادات المستخدمين».
├── settings.json     إعدادات البرنامج المشتركة (الخطوط والأعمدة…) يقرؤها البرنامج من GitHub.
├── sw.js             Service Worker: يحفظ الصفحة ليعمل البرنامج دون إنترنت. يجب أن يبقى في الجذر.
├── manifest.json     بيانات تثبيت البرنامج كتطبيق (الاسم والأيقونة). يبقى في الجذر.
├── web/              ملفات الواجهة (ما يعمل في المتصفح)
├── server/           ملفات الخادم المحلي (ما يعمل على جهاز/خادم الشبكة بـ Node.js)
├── scan-bridge/      وسيط السكانر (يعمل على الكمبيوتر الموصول به السكانر)
├── tools/            أدوات مساعدة تُشغَّل يدوياً
├── vendor/           المكتبات المحلية للعمل دون إنترنت
└── docs/             التوثيق والملفات القديمة
```

## web/ — الواجهة
| الملف | وظيفته |
|---|---|
| `js/script.js` | البرنامج الرئيسي: قراءة ملف الحاويات، الجداول والتبويبات، التقارير، رفع الملف |
| `js/archive.js` | نافذة الأرشيف: البحث، الرفع، المزامنة، فهرسة المحتوى |
| `js/auth.js` | تسجيل الدخول والمستخدمون والصلاحيات |
| `js/users-admin.js` | شاشة «⚙️ إعدادات المستخدمين» للمدير (إنشاء `users.json`) |
| `js/scanner.js` | شاشة المسح الضوئي والكاميرا ومعالجة الصور وOCR |
| `js/dashboard.js` | لوحة المعلومات (إحصاءات المسح والنسخ الاحتياطي) |
| `js/local-server.js` | ربط المتصفح بالخادم المحلي (الرفع/التنزيل المحلي) |
| `js/offline.js` | طابور رفع GitHub المؤجَّل عند انقطاع الإنترنت |
| `js/libs.js` | تحميل المكتبات: المحلية من `vendor/` ثم CDN |
| `js/pdf-text.js`، `js/pdf-font.js` | توليد تقارير PDF نصية (الخط العربي) |
| `css/dashboard.css`، `css/style.css` | التنسيقات (`style.css` غير مستخدم حالياً) |
| `img/icon.svg` | أيقونة التطبيق |

## server/ — الخادم المحلي (Node.js)
- `server.js`: خادم الأرشيف على الشبكة (يحفظ الملفات، `/api/users` لتسجيل الدخول دون إنترنت).
- `package.json`: مكتباته. `start-server.bat`: **شغّله لتشغيل الخادم** (يثبّت المكتبات أول مرة في `server/node_modules`).
- `users.cache.json`: نسخة من المستخدمين يحدّثها الخادم تلقائياً (تُنشأ عند التشغيل).

## scan-bridge/ — وسيط السكانر
يشغّله من يملك السكانر: `start-scan-bridge.bat` (وملفات التشغيل التلقائي مع ويندوز). الشرح في `README-scan-bridge.txt`.

## tools/ — أدوات يدوية
- `download-libs.bat` / `.js`: تنزيل المكتبات إلى `vendor/` مرة واحدة (للعمل دون إنترنت).
- `backup-repo.bat` / `.sh`: نسخ احتياطي لمستودع GitHub.
- `pdf-test.html`: صفحة اختبار توليد PDF النصي.

## vendor/ — المكتبات المحلية
فارغ حتى تشغّل `tools/download-libs.bat`. إن كان فارغاً يستخدم البرنامج CDN كما كان.

## docs/ — التوثيق
- `README.md`: الدليل الكامل وسجل كل التحديثات.
- `users.sha256.example.json`: مثال لملف مستخدمين بكلمات مرور مشفّرة.
- `old-versions/`: ملفات قديمة غير مستخدمة (للرجوع إليها فقط).

## ماذا يُرفع إلى GitHub وماذا يبقى على الخادم؟
- **GitHub (الموقع):** `index.html` و`users.json` و`settings.json` و`sw.js` و`manifest.json` و`web/` و`vendor/` (بعد تنزيل المكتبات).
- **جهاز الخادم المحلي:** `server/`. **جهاز السكانر:** `scan-bridge/`.
- `tools/` و`docs/` اختيارية.
