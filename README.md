# نسختك الأصلية + التصميم الجديد (شكل وتنسيق فقط)

## ما أُضيف
- `dashboard.css` — المظهر الجديد: ألوان، أزرار متدرجة بحركات، بطاقات، جداول، نوافذ، الوضع الليلي/النهاري.
- `dashboard.js` — القائمة الجانبية، لوحة المؤشرات، شريط الأدوات القابل للطي، شريط «تحميل من GitHub» القابل للطي، زر الوضع الليلي، وتلوين الأزرار.
- `index.html` — ثلاثة أسطر فقط: رابط `dashboard.css` قبل `auth.js`، وسكربت `dashboard.js` بعد `script.js`.

## ما لم يُمسّ (مطابق لنسختك بايتاً ببايت)
`script.js` `archive.js` `auth.js` `local-server.js` `server.js` `users.json` `package.json` `start-server.bat` `settings.json` `copy.json` `style.css`

## الرفع
- إلى GitHub (أو مجلد التطبيق): `index.html` و`dashboard.css` و`dashboard.js`.
- الخادم والمستخدمون والدخول: كما كانت تماماً، لا حاجة لأي تغيير.

## للتراجع
احذف `dashboard.css` و`dashboard.js` والأسطر الثلاثة من `index.html` فيعود البرنامج كما كان.

## 4.1 — تسريع لوحة المؤشرات (في dashboard.js فقط)
- تظهر آخر نسخة محفوظة فوراً، ثم تُحدَّث.
- المصدران (المحلي وGitHub) يُحمَّلان بالتوازي، ويُعرض كل منهما فور وصوله.
- لا يُعاد كشف الخادم المحلي إن كان معروفاً.
- مهلة 8 ثوانٍ لفهرس GitHub.

## 4.2 — تحديث تلقائي للوحة
- فحص هادئ كل 30 ثانية (المحلي كل 60) وعند العودة للصفحة؛ يتحدث المحتوى وتظهر رسالة «🔔 تمت إضافة N ملف جديد» عند وجود جديد فقط.
- تحديث فوري بعد رفع/حذف المستخدم نفسه في الأرشيف المحلي.
- لا يستبدل بيانات سليمة بنتيجة فاشلة، ولا يعمل والتبويب مخفي أو خارج اللوحة.

## 4.3 — تخفيف حمل التحديث التلقائي
- فهرس GitHub في الفحص الدوري: طلب شرطي (يعود 304 بلا محتوى إن لم يتغير). التنزيل الكامل فقط عند فتح اللوحة، أو «تحديث»، أو بعد رفعك أنت.
- الفحص كل دقيقة لـ GitHub وكل دقيقتين للأرشيف المحلي (كان 30 و60 ثانية).

## 5.0 — تقرير PDF نصي (أصغر حجماً، يراعي اختيار الأعمدة)

**ما تغيّر**
- `script.js`: عشرة أسطر فقط داخل `autoGenerateAndArchiveFullPDF`، تستدعي المولّد الجديد أولاً، وتعود للطريقة الصورية الأصلية (دون تغيير فيها) عند أي فشل.
- `pdf-text.js` (جديد): يقرأ الجداول **الحيّة** من الصفحة، فيطابق ما تراه: الأعمدة المختارة، والصفوف المعروضة (بعد الفلترة)، وألوان الخلايا والشارات، وبطاقات الإجمالي، وبيانات Finalout، والتوقيعات، والتذييل، وعمود «م».
- `pdf-font.js` (جديد): خط عربي مُصغَّر (DejaVu، ترخيص حر) مضمَّن في الملف، مع تشكيل الحروف وترتيب RTL.
- `index.html`: سطرا سكربت جديدان.

**الفروق عن الطريقة الصورية**
- الصفحات **طولية A4** كما طلبت. حجم الخط يتكيّف مع عدد الأعمدة: نحو 8pt لثمانية أعمدة، و5.2pt لـ 19 عموداً، و4.4pt لـ 22 عموداً (مثل الصورة المصغّرة الحالية)، وتُقسَّم العناوين الطويلة إلى أسطر بالترتيب العربي الصحيح.
- الأيقونات التعبيرية (📦 🚢 📅 …) تُحذف من العناوين، و❌/✅ تظهر ✖/✔ بنفس معناها.
- الأرقام العربية-الهندية تتحول إلى أرقام لاتينية، وتاريخ الطباعة بصيغة dd/mm/yyyy.
- النص قابل للبحث والنسخ، وترويسة الجدول تتكرر في كل صفحة.

**الرجوع للقديم:** `localStorage.setItem('pdfMode','image')` في Console، أو احذف الأسطر العشرة.

**قبل الاعتماد عليه:** افتح `pdf-test.html` من نفس مكان `index.html` (يحتاج إنترنت لتحميل jsPDF) واضغط الزر؛ ثم أنشئ تقريراً حقيقياً لسفينة واحدة وقارنه بالقديم.

**5.1:** إصلاح الخط العريض (كان العنوان وقيم البطاقات تظهر بخط آخر مشوّه)، وتحويل الصفحات إلى طولية.

**5.2:** بطاقات الإجمالي تُقرأ وتُرسم كما هي في الصفحة: ألوان البطاقات (التدرجات تُرسم بمتوسط لونيها)، العنوان والرقم الكبير والأسطر التفصيلية (20/40 قدم، OOG، Hazardous، Flex String، Dray...) وأشرطة الخلفية الملوّنة داخلها، وتلتف الأسطر الطويلة بترتيب عربي صحيح. كانت تُقرأ سابقاً نصاً واحداً طويلاً بخط مجهري.

**5.3 (إصلاح العربية المعكوسة):** تبيّن أن jsPDF يعيد ترتيب أي نص يحوي حروفاً عربية بنفسه، فكان يعكس الترتيب الذي أجهّزه (الكلمات والحروف تظهر معكوسة). صارت الحروف العربية تُمرَّر إلى المكتبة برموز الاستخدام الخاص (E200–E7FF) وتُعرَض بالأشكال الصحيحة عبر الخط المضمَّن، فلا تتدخل المكتبة في ترتيبها. الاختبار الآلي يفشل الآن إن وصل إليها أي حرف عربي بترميزه الأصلي.
